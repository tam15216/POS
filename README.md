# 🛒 POS & Inventory Management System

ระบบบริหารจัดการร้านค้า ณ จุดขาย (Point of Sale) และระบบควบคุมคลังวัตถุดิบ/สินค้าคงคลังเต็มรูปแบบ พัฒนาขึ้นด้วยสถาปัตยกรรม **Full-Stack JavaScript** ที่เน้นความเป็นระเบียบ การแยกส่วนการทำงานอย่างชัดเจน (Separation of Concerns) และโครงสร้างโค้ดฝั่ง Backend แบบ Component-Based/Modular Design (`Route`, `Controller`, `Service`, `Repository`) 

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite), Tailwind CSS, React Hooks & Context API
* **Backend:** Node.js, Express, JSON Web Token (JWT)
* **Database:** MySQL (เชื่อมต่อผ่านโมดูล `mysql2` ด้วย Repository Pattern)

---

## 📋 ฟังก์ชันการทำงานของระบบ (System Features)

### 1. ระบบสมาชิกและการยืนยันตัวตน (Authentication & User Module)
ระบบความปลอดภัยและการจำกัดสิทธิ์การเข้าถึงข้อมูลตามบทบาทหน้าที่ (Role-Based Access Control)
* **Sign In / Sign Out:** ระบบตรวจสอบสิทธิ์ผู้ใช้งานผ่าน Username และ Password พร้อมการเข้ารหัสข้อมูลที่รัดกุม
* **Session Management:** ระบบออก **JSON Web Token (JWT)** เพื่อใช้เป็นสิทธิ์ (Bearer Token) ในการเข้าถึง API แต่ละส่วนอย่างปลอดภัยผ่าน Authentication Middleware
* **Role-Based Filtering:** Middleware คัดกรองและจำกัดสิทธิ์การเข้าถึงหน้าจอและ API ระหว่างผู้บริหาร (Admin) และพนักงานทั่วไป (Staff)
* **User Management:** ระบบจัดการข้อมูลพนักงาน (เพิ่ม, ลบ, แก้ไข) และการเปิด-ปิดสถานะการทำงาน (Active/Inactive) ของผู้ใช้งานในระบบ

### 2. ระบบจัดการสินค้าและหมวดหมู่ (Product & Category Module)
ระบบบริหารจัดการข้อมูลสินค้าหน้าร้าน
* **Category Management:** ระบบสร้างและจัดการหมวดหมู่สินค้า (เช่น เครื่องดื่ม, ของทานเล่น) เพื่อใช้ในการจัดกลุ่มและกรองสินค้าที่หน้าร้าน POS
* **Product CRUD Operations:** ระบบจัดการข้อมูลสินค้าคงคลัง (เพิ่ม, อ่าน, แก้ไข, ลบ) บันทึกข้อมูลชื่อสินค้า, ราคา, ต้นทุน และสถานะการวางจำหน่าย
* **Product Matching:** ฟังก์ชันค้นหาและดึงรายการสินค้าแยกตามหมวดหมู่ เพื่ออำนวยความสะดวกในการแสดงผลฝั่ง UI

### 3. ระบบขายหน้าร้านและจัดการคำสั่งซื้อ (POS & Order Module)
หัวใจหลักของระบบขายที่คำนวณและประมวลผลข้อมูลแบบ Real-time
* **Cart & Order Processing:** ระบบตะกร้าสินค้าหน้าร้าน รองรับการเพิ่ม/ลดจำนวนสินค้า และการคำนวณยอดรวมราคาสินค้าโดยอัตโนมัติ
* **Product Customization Options:** รองรับการเลือก Option เสริมของสินค้า (เช่น ระดับความหวาน, ประเภทน้ำแข็ง, ท็อปปิ้ง) โดยตัวระบบจะคำนวณราคาส่วนเพิ่มเข้าไปในออเดอร์โดยอัตโนมัติ
* **Checkout & Payment Gateway:** ฟังก์ชันปิดยอดขายและบันทึกบิล รองรับการชำระเงินหลายรูปแบบ เช่น เงินสด และการโอนจ่าย
* **Inventory Deduction Lookup:** ทันทีที่มีการสั่งซื้อสำเร็จ ระบบจะสั่งการให้ไปคำนวณและตัดยอดวัตถุดิบในคลังสินค้าตามสูตรผลิตโดยอัตโนมัติ
* **Order History & Bill Search:** ระบบสืบค้นรายการคำสั่งซื้อย้อนหลัง ค้นหาบิลตามรหัสบิล หรือกรองตามสถานะ เพื่อใช้ตรวจสอบความถูกต้องหรือทำการยกเลิกออเดอร์

### 4. ระบบสูตรการผลิตและจัดการวัตถุดิบ (Recipe & Ingredient Module)
ระบบคำนวณต้นทุนแฝงและตัดสต็อกระดับวัตถุดิบ (Bill of Materials - BOM)
* **Ingredient Management:** ระบบควบคุมคลังวัตถุดิบหลัก (เช่น เมล็ดกาแฟ, นมสด, แก้วพลาสติก) บันทึกหน่วยนับ และกำหนดจุดสั่งซื้อขั้นต่ำ (Low Stock Threshold)
* **Recipe Builder (BOM):** ระบบผูกสูตรสินค้าเข้ากับวัตถุดิบ (เช่น กาแฟลาเต้ 1 แก้ว ประกอบด้วย เมล็ดกาแฟ 18 กรัม + นมสด 120 มล. + แก้ว 1 ใบ) รองรับการผูกสูตรเข้ากับ Option เสริมของสินค้าด้วย
* **Real-time Stock Deduction:** ฟังก์ชันหักลบวัตถุดิบในคลังสินค้าอัตโนมัติเมื่อเกิดรายการขาย โดยคำนวณตามหน่วยและปริมาณที่ใช้จริงในสูตรผลิต

### 5. ระบบบริหารคลังสินค้าและการรับเข้า (Stock & Inventory Module)
ระบบบันทึกประวัติและเคลื่อนไหวของสินค้าคงคลัง
* **Restocking & Adjustment:** ระบบบันทึกการรับเข้าวัตถุดิบ (Restock) เพิ่มจำนวนวัตถุดิบเข้าคลังพร้อมบันทึกราคาต้นทุนล็อตล่าสุด
* **Transaction Tracking:** บันทึกประวัติการเคลื่อนไหวของสินค้าและวัตถุดิบทุกประเภท (Stock Movement) ระบุเหตุผลการเปลี่ยนแปลง เช่น บันทึกจากการขาย, บันทึกจากการรับเข้า หรือบันทึกจากการปรับยอดสินค้าชำรุด

### 6. ระบบรายงานและวิเคราะห์ข้อมูล (Dashboard & Report Module)
ระบบประมวลผลเพื่อการตัดสินใจทางธุรกิจ (Business Intelligence)
* **Dashboard Summary Metrics:** ฟังก์ชันคำนวณยอดขายรวม, จำนวนออเดอร์, และแยกประเภทเงินสด/เงินโอน ประจำวันเพื่อแสดงผลเป็น Summary Cards ทันทีที่เข้าสู่ระบบ
* **Sales Reports:** ระบบรายงานยอดขายเชิงลึก สามารถกรองข้อมูลตามช่วงเวลา (Daily, Weekly, Monthly) เพื่อดูแนวโน้มการเติบโตของร้านค้า
* **Top Selling Products Report:** ฟังก์ชันดึงข้อมูลสรุปอันดับสินค้าขายดี (Top Products) วิเคราะห์รายการสินค้าที่ทำกำไรสูงสุด
* **Low Stock Alerts:** ระบบแจ้งเตือนรายการวัตถุดิบที่เหลือปริมาณน้อยกว่าเกณฑ์ขั้นต่ำที่กำหนดไว้ เพื่อป้องกันปัญหาวัตถุดิบขาดแคลนหน้าร้าน
* **Stock Movement Report:** รายงานสรุปภาพรวมการเข้า-ออกของวัตถุดิบในคลัง ช่วยให้ผู้บริหารตรวจสอบการทุจริตหรือสินค้าสูญหายได้ง่ายขึ้น
